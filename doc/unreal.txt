1. Introduction                                          *unreal-introduction*

                                                                 *unreal.nvim*

**unreal.nvim** helps working on Unreal Engine C++ projects: source/header
switching, clangd compilation-database generation, `UFUNCTION`/`UCLASS` macro
attribute completion, function implementation stubbing, and Unreal-aware
treesitter/telescope integration.


  **Warning:** this plugin is a work in progress. Commands, config options, and
  behavior may change without notice.

FEATURES                                        *unreal-introduction-features*

- Switch between header and source
- Generate function implementation stubs from a header declaration
- Rebuild the clangd compilation database
- Complete `UCLASS`/`USTRUCT`/`UFUNCTION`/`UPROPERTY` macro attributes
- Find/grep source files via telescope
- Open the `.uproject` in the Unreal editor
- Per-project engine path, cached across sessions
- Unreal-aware treesitter grammar and telescope ignore patterns


ACKNOWLEDGEMENTS                        *unreal-introduction-acknowledgements*

The custom Unreal C++ treesitter grammar is tree-sitter-unreal-cpp
<https://github.com/taku25/tree-sitter-unreal-cpp> by taku25
<https://github.com/taku25>.

2. Installation                                          *unreal-installation*


REQUIREMENTS                                *unreal-installation-requirements*

- Neovim >= 0.12
- nvim-treesitter <https://github.com/nvim-treesitter/nvim-treesitter>
- telescope.nvim <https://github.com/nvim-telescope/telescope.nvim>
- plenary.nvim <https://github.com/nvim-lua/plenary.nvim>
- nvim-lspconfig <https://github.com/neovim/nvim-lspconfig>
- `rg`, `clangd` and `dotnet` on `$PATH`
- An installed Unreal Engine build

Use the nvim-treesitter `main` branch; `master` is not supported.
nvim-lspconfig needs clangd set up: it provides `:LspClangdSwitchSourceHeader`,
the fallback of |unreal-commands-switchsourceheader|.


LAZY.NVIM                                      *unreal-installation-lazy.nvim*

>lua
    {
        "lckdG/unreal.nvim",
        dependencies = {
            { "nvim-treesitter/nvim-treesitter", branch = "main" },
            "nvim-telescope/telescope.nvim",
            "nvim-lua/plenary.nvim",
            "neovim/nvim-lspconfig",
        },
        opts = {},
    }
<

Or call `setup()` yourself:

>lua
    require('unreal').setup({})
<


TREE-SITTER GRAMMAR                  *unreal-installation-tree-sitter-grammar*

After installing, run `:TSUpdate cpp` once so nvim-treesitter builds the Unreal
C++ grammar.

The plugin replaces nvim-treesitter’s `cpp` parser with
tree-sitter-unreal-cpp <https://github.com/taku25/tree-sitter-unreal-cpp>. This
applies to every C++ file, not only Unreal projects, and there is no opt-out:
|unreal-commands-createimpl| and |unreal-commands-completemacro| depend on it.

3. Config                                                      *unreal-config*

All options are optional. Defaults:

>lua
    require('unreal').setup({
        custom_treesitter = {
            url = 'https://github.com/taku25/tree-sitter-unreal-cpp',
            revision = '2d2d5c19a9a83e432e43c041252106995614b29a',
        },
        command_lead = "Unreal",
        cmd_abbreviations = {},
        telescope_extended_ignores = { --[[ Unreal defaults, see below ]] },
        clangd_build_args = { "-NoExecCodeGenActions" },
    })
<


CUSTOM_TREESITTER                            *unreal-config-custom_treesitter*

Grammar registered as nvim-treesitter’s `cpp` parser. Override `url` and
`revision` to pin another build of the grammar.


COMMAND_LEAD                                      *unreal-config-command_lead*

Name of the user command. With `command_lead = "UE"` the commands become `:UE
OpenProject`, `:UE RebuildClangd`, …


CMD_ABBREVIATIONS                            *unreal-config-cmd_abbreviations*

Command-line abbreviations, expanded to `<command_lead> <value>`:

>lua
    cmd_abbreviations = { uo = "OpenProject", uc = "RebuildClangd" }
<


TELESCOPE_EXTENDED_IGNORES          *unreal-config-telescope_extended_ignores*

Lua patterns appended to telescope’s global `file_ignore_patterns`, so they
apply to every telescope picker, not only |unreal-commands-findsource| /
|unreal-commands-grepsource|.

Setting this **replaces** the defaults (Unreal binaries, assets and generated
directories such as `Binaries/` and `Intermediate/`). To keep them, copy the
list from `require('unreal.config').defaults.telescope_extended_ignores` and
edit it.


CLANGD_BUILD_ARGS                            *unreal-config-clangd_build_args*

Extra arguments for the UnrealBuildTool `-mode=GenerateClangDatabase` call made
by |unreal-commands-rebuildclangd|. Each entry is one argument.

4. Commands                                                  *unreal-commands*

                                                                     *:Unreal*

All commands are subcommands of `:Unreal` (see |unreal-config-command_lead|),
with `<Tab>` completion. If several `.uproject` files are found, commands that
need one prompt you to choose.


SETENGINEPATH                                  *unreal-commands-setenginepath*

Prompt for the engine path of the current project and save it. See
|unreal-engine-path|.


OPENPROJECT                                      *unreal-commands-openproject*

Open the `.uproject` in the working directory in the Unreal editor (on Windows,
with the default handler).


REBUILDCLANGD                                  *unreal-commands-rebuildclangd*

Regenerate `compile_commands.json` with UnrealBuildTool and copy it into the
working directory. Output is shown in a terminal split; press any key to close
it when the build is done.


SWITCHSOURCEHEADER                        *unreal-commands-switchsourceheader*

Switch between a header and its source file. Searches the module’s
`Public`/`Private` folders first, then falls back to clangd.


CREATEIMPL                                        *unreal-commands-createimpl*

With the cursor on a function declaration in a header, append an implementation
stub to the matching `.cpp`, or jump to it if it exists.

- `BlueprintNativeEvent` and RPC functions: `_Implementation` stub
- `WithValidation`: also a `_Validate` stub
- `BlueprintImplementableEvent`: no stub
- Pure virtual, deleted and inline functions: no stub


COMPLETEMACRO                                  *unreal-commands-completemacro*

Complete a `UCLASS`/`USTRUCT`/`UFUNCTION`/`UPROPERTY` specifier under the
cursor. Requires clangd.


FINDSOURCE                                        *unreal-commands-findsource*

Find header, source, or both kinds of files with telescope.


GREPSOURCE                                        *unreal-commands-grepsource*

Live grep header, source, or both kinds of files with telescope.

5. Engine path                                            *unreal-engine-path*

The engine path is stored per project, keyed by the nearest `.uproject`
directory found upward from the working directory, in
`stdpath('data')/unreal.nvim/lock.dat`.

A path is valid only if it contains
`Engine/Binaries/DotNET/UnrealBuildTool/UnrealBuildTool.dll`. Commands that
need the engine prompt for a path when none is saved, the saved one is no
longer valid, or the working directory moved to another project.

6. Health                                                      *unreal-health*

Run `:checkhealth unreal` to check:

- `setup()` was called
- telescope.nvim, plenary.nvim, `rg`, `clangd` and `dotnet` are available
- the saved engine path, the editor executable and UnrealBuildTool exist
